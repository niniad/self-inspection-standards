# 第1章 共通事項

## 1.1 自主点検の目的・位置づけ

自主点検は、財務報告の信頼性を確保するため、AWグループの会計方針が確実に浸透・理解され、AW本社を含む各社における会計処理が当社グループの会計方針と整合した形で実施されていることを各社自らが点検する仕組みである。

自主点検は以下の二つを目的として実施する。
- 財務報告の信頼性を確保する
- 内部統制上の課題、不備を補完する

自主点検は、AWグループの決算の適切性を担保するものであり、**半期報告書提出時に各社に要請される宣誓書の基礎となる事項** である。各位、自主点検の結果には誠実かつ厳格に向き合うこと。

> 出典：26期経理室 通達第1号

## 1.2 適用範囲

- **対象会社**：連結会社全社（エア・ウォーター株式会社およびすべての連結子会社）
- ※持分法適用関連会社および持分法非適用関連会社は対象外（固定資産現物実査の場合）
- **対象期間**：FY2026年3月期（FY2025年4月〜FY2026年3月）を基本期間とし、項目により対象月・対象基準日が異なる（各項目章を参照）

> 出典：26期経理室 通達第1号／27期経理室 通達第2号

## 1.4 外部証憑による確認の徹底

自主点検は、手続の形式的な実施ではなく、**その実効性および証拠力を厳格に確保する** ことが必須である。

各勘定科目・取引に係る根拠証憑との照合手続については、**システム帳票や社内作成資料等の内部帳票の確認のみで完了することは原則認められない**。必ず、より証拠力の高い **外部証憑（社外から発行された資料等）** を用いた確認を実施すること。

### 必須となる外部証憑（カテゴリ別）

**【売上】**
- 得意先との契約書、注文書
- 納品書、作業完了報告書、検収書の控え、送り状等
- 顧客発行の返品依頼書、不具合報告書
- 顧客との協議議事録、メール等のやり取り
- 再発行した請求書 等

**【仕入】**
- 仕入先との契約書、注文書
- 仕入先発行の請求書
- 納品書、検収書 等
- 仕入先の正式な見積書（固定資産の場合）

**【固定資産・除却】**
- 除却申請書
- 廃棄証明書、廃棄リスト等、除却の事実を外部的に確認できる資料

**【経費】**
- 社外発行の領収書、請求書
- クレジットカード会社発行の利用明細
- 外部業者との契約書、見積書 等

> 出典：【重要】決算自主点検_外部証憑確認徹底のお願い

- データソース（システム名、テーブル名、画面名など）
- 抽出条件（対象期間、フィルタ条件、抽出パラメータなど）
- 抽出手順（操作ステップ）
- SQL・スクリプトを使用した場合は、そのコード本体

## 1.6 妨害行為の禁止と誠実対応の要請

調査・監査の過程において妨害行為（改ざん、隠ぺい等）は厳に慎むこと。妨害とみなされる行為には、**妨害を意図していない事実と異なる資料提出や発言** も含まれる。自身の提出資料や発言が虚偽にあたらないか、厳に注意を払って対応すること。

自主点検は本社へ資料を提出して完結するものではなく、内容や検討過程について、本社または会計監査人からの照会が行われる可能性を前提として対応すること。

> 出典：26期経理室 通達第1号／体制構築のお願い

# 第2章 各点検項目

## No.01 売掛金の残高確認

### 基本情報

| 項目 | 内容 |
|------|------|
| 関連科目 | 売掛金、売上 |
| 対象会社 | 全社（連結会社全社） |
| 対象期間 | FY2026年3月末（原則全社全件） |
| 対応論点 | 実態のない売上計上（根拠証憑に基づかない売上計上、本人代理人取引、循環取引など）／検収未完了や分割検収による売上の前倒し計上、既完了案件の売上の後倒し計上 |

### 確認方法

1. 自社が有する売掛金（一部の売掛金は発送対象外）に対し、3月末残高に対する **残高確認状** を発送する。
2. 残高確認状の **回収のみならず、帳簿金額と回答金額との差異調整** を実施する。
3. 確認状を発送できない（または回収できない）相手先（個人・官公庁等を含む）については、後述の **代替手続** を実施する。

### 確認状が回収できなかった場合の代替手続

確認状を発送したものの回収できなかった得意先については、以下の証憑を用いた代替手続を実施する。

| 区分 | 注文書 | 着荷証票又は検収証票（※1） | 入金証票 | 請求書 |
|------|--------|----------------------------|----------|--------|
| 4月末までに入金がある得意先 | △（但し書き要確認） | 〇（※2） | ― | 〇 |
| 4月末までに入金がない得意先 | 〇（但し書き要確認） | ―（※3） | ― | 〇 |

- ※1 着荷基準で売上計上している会社は着荷証票、検収基準で売上計上している会社は検収証票と照合する。
- ※2 入金があることを踏まえ、2026/3単月の売上分のみから発生した売掛金残高について証憑を準備する。
- ※3 入金証票が無いため、売上計上時期に関わらず、全ての売掛金残高について証票を準備する。ただし、2026/3単月の売上計上分は No.8「売上明細データのチェック」が実施されることを前提とすれば、新たに着荷証票または検収証票を取り寄せる必要があるのは「4月末までに入金がない＆2026/2以前に発生した売上に係る売掛金残高」に限定される。

### 確認状を発送していない相手先（個人・官公庁等）に対する代替手続

**（1）入金消込プロセスの確認**

以下3項目をすべて満たしていることを「代替手続チェックリスト」に記載・提出する。
- 得意先の請求単位毎に、売掛金の入金消込処理ができているか
- 個別消込は全ての売上取引について実施しているか
- 入金消込の結果が「入金消込管理表」に出力・トレースが可能か

3項目すべてYesの場合は（2）へ進む。1項目でもNoがある場合には自社のプロセスを詳細に記述し、（4）追加サンプリングへ進む。

**（2）入金消込管理表の正確性・網羅性の証明**

- **正確性検討**：未入金リストのうち任意1件を請求書と照合（金額・入金予定日の一致）／2026年4月入金分の任意1件をbank statementと照合（金額・実際入金日の一致）／2026年3月末の未入金リストが売掛金残高明細表と整合
- **網羅性検討**：4月中入金予定にもかかわらず消し込まれていない残高がないか／差異がある場合はその内容を明確化／5月中入金予定のうち違算可能性が高いものを確認
- 6月以降入金残高の合計が10百万円未満（対象相手先全件の合計値）の場合は（4）の手続は不要

**（3）売掛金カットオフテスト**

2026年3月（単月）の売上取引について、売掛金明細と着荷証票又は検収証票を突合する。No.8と重複するため、No.8を実施できている会社は追加手続不要。

**（4）（必要に応じて）追加サンプリング**

2026年6月以降入金予定の3月末売掛金残高が10百万円以上の場合に実施。
- 当該残高（残余母集団）の金額・比率・件数・単価の趨勢分析を過去3年間にわたり実施
- エクセルのランダム関数を使用して10件サンプリングし、売掛金明細と着荷証票又は検収証票を突合

### 親会社（AWI）に提出する成果物

1. 残高確認状の回収結果、差異調整結果
2. 代替手続実施結果（「代替手続チェックリスト」、入金消込管理表の検証資料、追加サンプリングの結果等）
3. 売掛金明細（2026年3月末）
4. 試算表（2026年3月末）
   ※売掛金明細 ⇒（調整）⇒ 試算表（BS）⇒（調整）⇒ 連結パッケージ の一連の証憑

### 提出先・体制

- **シェアポイント格納先**：各社SharePoint `債権残高確認 ＞ 会社提出資料` 直下（コントロールシート格納場所と同じ）
- 格納権限付与は債権残高確認事務局に申請、権限付与不可の場合は事務局メールへ送信
- 担当者が実施した代替手続の結果は **上席者が必ず確認** する（レビュー体制）

### 提出期日（運用例）

- 外部監査人による監査対象会社：5月7日
- それ以外：5月13日

## No.03 固定資産の実査

### 基本情報

| 項目 | 内容 |
|------|------|
| 関連科目 | 固定資産 |
| 対象会社 | 全社（連結会社全社）／持分法適用関連会社および持分法非適用関連会社は対象外 |
| 対象期間 | FY2026年3月末（原則全社全件） |
| 対応論点 | 固定資産の除却損漏れ／資産性のない支出の固定資産計上 |

### 基準日・対象資産

- **基準日**：3月末。実査は4月下旬までに実施し、ロールバック（基準日以降の期間について書類にて確認すること）を行う。
- **対象資産**：有形固定資産全件（リース資産含む）
  - 建物（建物付属設備を含む）および構築物
  - 機械装置および運搬具
  - 工具器具および備品
  - 土地
  - 建設仮勘定
  - 貯蔵品に含まれる予備品（設備予備品）のうち、実地棚卸対象外のもの

### 実施方法（実査前準備）

- あらかじめ対象資産が視認できるかを理解する
- 修繕費・人件費を固定資産として計上している場合には、固定資産実査前において、**当該固定資産の資産性について検証** し、固定資産実査表の備考欄に記載する
- 以下を用意する：
  - 実査表、固定資産台帳（固定資産台帳がない場合は、物件の所在地、取得価額、期末簿価、取得年月日、償却方法が網羅的に記載された資料）
  - カメラ（撮影に用いる）
  - ロケーション図（資産の位置関係が分かるもの）
- 実査表に固定資産台帳等から必要な情報を転記する（固定資産台帳の金額が試算表と一致することを確認）
- 基準日以降に実査を実施する場合は、3/31から実査日までの期間に取得・除売却した有形固定資産が存在する場合、当該取得等の根拠と突合（ロールバック）

### 実施方法（実査時）

- **現場担当者2名以上で1チーム** とする
- 固定資産台帳の資産について、現物の有無を確認する
- 実査した証跡として **写真（日付、現物が写っているもの）** を残す
- 実査表の「現物から転記」列に数量、単位、状態を記載する
- 資産の物理的状態、使用状況及び将来使用予定の有無を確認する
- 遊休資産、長期滞留している建設仮勘定の有無を確認する

### 現物カウント以外を採用する場合

現物カウントを行うことが原則であるが、以下の場合は現物カウント以外の方法を採用することを可能とする。ただしその場合でも、実査表「備考欄」に **理由・代替手続の内容を記載** する必要がある。

- 建物または土地は、登記簿等で実在性することが明らかな場合、登記簿等と照合
- リース資産のうち社宅・車両は、リース契約書と照合
- 個人に貸与し、かつ敷地に入れないため現物カウントが困難な資産を、貸与契約書と照合
- 設備に組み込まれている等の事情により視認が難しい資産は、使用実績を裏付けるその他の証拠（年次点検記録・メンテ履歴・修理履歴／電力使用・稼働ログ・システムログ／付保状況一覧 等）により実在性が確かめられる場合、当該書類を以て現物カウントに替えることができる

### 写真の要件

- **タイムスタンプ付きのカメラアプリ** を使用して撮影、またはノートに日付を記載したものを写真に入れる
- データ形式：**JPEG**、ファイルサイズは **1600×1400 を標準** に変更（ファイルサイズを軽くする）
- ファイル名：**資産番号（親番号10桁＋枝番号3桁）0詰め**（例：`0000012345001.jpg`）

### 写真撮影が困難な資産の代替証憑

- 土地：直近の固定資産税の課税明細、または登記簿を代替証憑とする
- 不動産取得税や資産除去債務の資産：元となる資産（建物、機械装置）と同じものとして扱う

## No.25 減損判定資料の作成及び提出

### 基本情報

| 項目 | 内容 |
|------|------|
| 関連科目 | 固定資産 |
| 対象会社 | 全社 |
| 対象期間 | FY2026年3月末 |
| 対応論点 | 減損損失の先送り・計上漏れ（のれん含む） |
| 提出期日 | 4/27（減損判定資料）／5/19（固定資産領域の内部統制・減損処理アンケート） |

### 確認方法

1. 当期末時点で **少なくとも日本基準の減損の兆候に抵触したCGU** について、割引後の将来キャッシュフローの算定を行った上で減損判定を行っているか（**日本基準で不要な場合でも、IFRS基準で減損損失の計上が必要な場合に備えて資料を作成しているか**）を確認する。
2. 行っていない場合、減損判定を行う。

### 親会社（AWI）に提出する成果物

1. **各CGUの減損判定資料**
2. **割引前将来キャッシュフロー及び割引後将来キャッシュフローの算定資料**
3. 固定資産領域の内部統制及び減損処理の実施に関するアンケート（フォーム回答）

### 兆候判定（日本基準）

- 営業活動から生ずる損益、CFが継続してマイナス
- 回収可能価額を著しく低下させる変化がある（例：遊休資産、長期滞留建設仮勘定等）
- 経営環境の著しい悪化
- 市場価格の著しい下落

### 認識判定

- **日本基準**：割引前CF＜帳簿価額
- **IFRS**：回収可能価額＜帳簿価額

### 日本基準とIFRSの差異

認識判定における、割引前CFと帳簿価額の比較はIFRSでは規定されていない。そのため、**割引前CF＞帳簿価額であっても、回収可能価額（割引後CF）と帳簿価額の比較をする必要がある**（IFRSでは日本基準で減損不要でも減損認識が必要なケースがある）。

### 成果物作成の流れ

1. **資産のグルーピング**：他の資産又は資産グループのキャッシュ・フローから概ね独立したキャッシュ・フローを生み出す最小の単位で行う（減損会計基準 二 6.(1)）
2. **兆候判定**：グルーピング単位ごとに、営業損益／CF・回収可能価額低下・経営環境・市場価格の各観点で兆候の有無を判定
3. **割引前将来CFと帳簿価額の比較（日本基準）**：兆候ありの場合、認識の判定を実施
4. **回収可能価額と帳簿価額の比較（IFRS）**：日本基準で認識しないとの結論でも、IFRSに照らし回収可能価額（使用価値・公正価値の高い方）との比較を実施
5. **回収可能価額と帳簿価額の比較（IFRS）の結果**：科目別に減損損失計上額を算定
